# Carrossel

Formato: **1080x1350 (4:5)**. Até 20 slides são permitidos, mas o ideal é **6 a 10**.

## Estrutura
| Slide | Função | Regra |
|---|---|---|
| 1 — Capa | Fazer arrastar | Promessa clara em até ~8 palavras + subtítulo opcional. Fonte grande, alto contraste |
| 2 — Ponte | Identificação | "Se você…" — mostra que é para a pessoa |
| 3 a N-2 — Conteúdo | Entregar valor | **Uma ideia por slide**, título + no máximo 2–3 linhas |
| N-1 — Resumo | Facilitar o salvamento | A lista inteira numa só tela |
| N — Fechamento | CTA | Um CTA (salvar / mandar / comentar) + @ do perfil |

## Tipos que funcionam no nicho
- "X sinais de que…" · "O que [conceito] significa na prática" · "Mito x verdade"
- "Perguntas para se fazer quando…" (exercício de reflexão — muito salvo)
- "Frases que você diz e o que elas podem esconder" (sem diagnóstico)

## Visual
- Cores e fontes de `memoria/voz-e-marca.md`. Margem de segurança de ~100 px.
- Texto legível no celular: título ≥ 60 px, corpo ≥ 36 px.
- Mesmo layout em todos os slides; a capa pode ser diferente.
- Se for gerar as imagens no ambiente: ImageMagick + fonte Inter (ver `Edi-o-videos/memoria/ambiente.md`).

## Entrega
Tabela slide a slide (texto exato de cada um + observação visual), 2 opções de capa,
legenda feita com a skill `legenda-instagram` e checklist ético.
