# Roteiro de Reels

Padrão da casa: 9:16, **30 a 60 s**, ritmo calmo, legenda de frase inteira
(ver `Edi-o-videos/memoria/estilo-de-edicao.md`).

## Passo 1 — Uma ideia, um público, um objetivo
Escreva em uma linha: "Para **[quem]** que **[sente/vive X]**, mostrar **[ideia]** para que
**[envie / salve / comente / agende]**." Se não couber numa linha, a ideia está grande demais.

## Passo 2 — 3 ganchos (0–3 s)
Escreva 3 ganchos de fórmulas diferentes e dê nota de 1 a 5 em: clareza do tema,
curiosidade, identificação, ética (sem medo/culpa). Recomende o melhor.

Fórmulas que funcionam no nicho de saúde mental:
1. **Espelho:** "Se você sempre pede desculpa até quando não errou…"
2. **Crença quebrada:** "Ansiedade não é falta de controle. É excesso dele."
3. **Pergunta íntima:** "Por que a gente se apega a quem não fica?"
4. **Sinais/lista:** "3 sinais de que você está se cobrando demais."
5. **Frase dita por alguém:** "'Eu só quero que você me entenda.' Quantas vezes você já disse isso?"
6. **Conceito simples:** "Freud tinha um nome para isso: repetição."
7. **Situação do dia a dia:** "Domingo à noite e aquele aperto no peito?"
8. **Contraste:** "Não é preguiça. É cansaço emocional."

O gancho aparece **falado e escrito na tela** ao mesmo tempo. Nada antes dele (sem vinheta, sem "oi gente").

## Passo 3 — Batidas cronometradas
| Tempo | Batida | Conteúdo |
|---|---|---|
| 0–3 s | Gancho | Frase + texto na tela |
| 3–10 s | Identificação | "Talvez você…" — a pessoa se reconhece |
| 10–40 s | Virada / explicação | O conceito em linguagem simples, 1 exemplo hipotético |
| 40–55 s | Fechamento | Uma frase que dá vontade de mandar para alguém |
| 55–60 s | CTA | Um só, ligado ao objetivo |

Regra: cada frase com no máximo ~12 palavras (vira uma legenda de frase inteira).
Ritmo de fala calmo ≈ 2 palavras por segundo → 60 s ≈ 110–120 palavras.

## Passo 4 — Entrega
```
# Título do vídeo
- Quem fala: ______ · Duração alvo: __ s · Objetivo: envio/salvamento/…
- Ganchos (nota): 1) … 2) … 3) …  → recomendado: _
- Texto falado (uma frase por linha):
  1. …
- Texto na tela (por tempo): 0 s "…", 10 s "…"
- Capa do Reel (texto curto, até 5 palavras): …
- Palavras-chave para a fala e a legenda: …
- Observações de edição: cortes, pausas, onde dar zoom
- Checklist ético: …
```
Salvar também em `Edi-o-videos/roteiros/AAAA-MM-DD-assunto.md` quando o repositório de vídeos
estiver disponível. Depois, fazer a legenda com a skill `legenda-instagram`.
